# MIND 2026 student application

Live form: https://forms.gle/s3jyVLcZRQVbqkBQ9

Use this specification to create the linked Google Form.

## Form settings

- Title: **MIND 2026 — Student application**
- Description: **14–15 December 2026 · Bizkaia Aretoa, Bilbao. There is no registration fee (€0). Places are limited; if applications exceed capacity, participants will be selected by the organising committee.**
- Collect email addresses.
- Limit to one response only if applicants can be expected to use a Google account.
- Allow response editing after submission.
- Store uploaded files in the event organisers' Google Drive.

## Questions

1. Full name — short answer, required
2. Email address — collected automatically, required
3. University or institution — short answer, required
4. Current degree programme — short answer, required
5. Current study level — multiple choice: Undergraduate / Master's / PhD / Other, required
6. City and country — short answer, required
7. Motivation letter — paragraph, required; suggested limit: 300–500 words
8. CV — file upload, required; PDF only; one file; maximum 10 MB
9. Dietary or accessibility requirements — paragraph, optional
10. Data-processing consent — checkbox, required: **I consent to the processing of my application data solely for managing selection and attendance for MIND 2026.**

## Confirmation message

**Thank you for applying to MIND 2026. Your application has been received. Attendance is free (€0). The organising committee will contact you after applications have been reviewed.**

The public Google Forms URL is linked from the application control in `src/pug/index.pug`.
