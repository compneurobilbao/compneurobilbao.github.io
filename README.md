# MIND 2026

Website for the International Meeting on Multiscale & Integrative Neuro-physiological Data, held at Bizkaia Aretoa in Bilbao on 14–15 December 2026.

## Editing

The editable source files are in `src/`:

- `src/pug/index.pug` — page content
- `src/scss/styles.scss` — styles
- `src/js/scripts.js` — navigation behaviour

Run `npm install` once and `npm run build` to generate the public `index.html`, `css/`, `js/`, and `assets/` files. Use `npm start` for a local live preview.

Ticket registration is linked from the homepage through Ticket Tailor.
